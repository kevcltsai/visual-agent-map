## 核心結構

每個研究主題使用獨立資料夾：

```text
Agent Workspace/
├── Topics/
│   └── <主題>/
│       ├── Map.md
│       ├── Notes/
│       ├── Unassigned/
│       └── Archive/
└── Inbox/
```

- `Map.md` 保存心智圖結構，是該圖的結構權威來源。
- `Notes` 保存目前在圖上的議題筆記。
- `Unassigned` 保存仍屬於主題、但已從圖上移除的筆記。
- `Archive` 保存停用的主題筆記；必須先取消封存才能重新認領。
- `Inbox` 保存無法判斷原始主題的舊孤兒筆記。

## 已交付功能

- 新增、開啟、重新命名及刪除研究主題；開啟 `Map.md` 時自動顯示心智圖。
- 新增根議題與子議題、拖曳、收合、縮放、改變母議題及防止循環連結。
- 從圖中移除單一節點或整個分支，保留 Markdown 筆記並移入 `Unassigned`。
- 認領、封存、取消封存，以及將筆記移至其他主題或直接加入其他心智圖。
- 節點 Model 繼承與個別調整；預設 `gpt-5.6-luna`，Codex 模型走 `codex-acp` 常駐 session，`claude:sonnet`、`claude:opus`、`claude:fable` 會改走 Claude Code CLI。
- 一般 AI 任務在送出前確認一次，完成後直接更新目前理解，並把 Detail 收斂成固定六段、可累積且去重的知識頁；AI 錯誤不改寫筆記正文。
- 工作台保留議題、目前理解、AI 規則與下一步；AI 規則是每次任務都會套用的長期限制，下一步則是單次任務。執行前會顯示本次套用規則，UI 不提供任務模式或待整理流程。
- 「整合議題」模式提供節點勾選、底部選取列，以及名稱／整合目標／AI 規則確認；AI 讀取完整來源知識後建立新根議題，來源可在工作台點回。
- 節點滑鼠預覽只顯示目前結論與 User Notes，支援最多 4 張 Markdown 圖片與第一個 Markdown 表格；預覽大小可用工具列滑桿調整。
- AI 回傳的視覺參考會整合進 Detail 內的「視覺參考」段落，不另外建立獨立 Visual References 區塊。
- 議題改名會同步檔名，AI 建立的子議題從一開始就使用議題名稱。
- 主工具列只保留高頻操作；筆記歸類集中於「整理」，心智圖管理集中於「更多…」。
- 詳情持續重用同一個右側 Markdown 欄；議題 Properties 預設收合。
- 工作階段內的復原與重做，以及外部 Markdown 更新、遺失檔案與衝突處理。
- 舊版全域 `Maps/Nodes` 經預覽與確認後才整理；失敗時回復已搬移的檔案。

## 開始使用

1. 依照[安裝說明](INSTALL.md)安裝並重新載入 Obsidian。
2. 開啟 Visual Agent Map，點「＋ 心智圖」建立主題資料夾。
3. 點「＋ 議題」開始建立圖面，再從議題工作台選擇下一步。
4. 若開啟舊版心智圖，從「更多…」使用「整理舊資料」查看預覽並自行確認遷移。
