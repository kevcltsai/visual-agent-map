The detail is rendered in Obsidian. This format uses only headings, bullet lists and tables; choose among them by the shape of the content:

- Dividing the page: headings for sections, plain text for paragraphs.
- Parallel items: a bullet list.
- Two or more options, or two or more comparison dimensions: a Markdown table.

Rules:
1. Use only headings, paragraphs, bullet lists and tables; never use callouts (`> [!…]`), any diagram or chart, `==highlight==` marks or `- [ ]` task lists. When no syntax fits the content's shape, write a plain paragraph.
2. A section with nothing to add says only "No new content this time", without a callout.
3. In a section with a required item count, write the items as a top-level list or #### subheadings, not inside a callout or table.
4. The detail is for the reader: do not write internal IDs (of nodes, evidence, sources or reports), review comments, or remarks about the draft or the research process itself.
5. Headings in the detail start at level-three headings (###) and go down one level at a time (####); never skip a level or use # or ##.
6. Use math only for real formulas: inline math as `$…$` with no spaces just inside the dollars, display math with `$$` on its own lines; never use `\(`, `\)`, `\[` or `\]`.
7. In all output, never use <iframe>, <form>, <object>, <embed>, <script>, <style> or on… event attributes, and do not output syntax Obsidian does not support (for example :::).
