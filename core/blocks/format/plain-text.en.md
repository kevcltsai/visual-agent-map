The detail is rendered in Obsidian. This format uses only plain paragraphs, lists and #### subheadings; it uses no callouts, tables, diagrams, task lists or highlights.

Rules:
1. In a section with a required item count, write the items as a top-level list or #### subheadings, not inside a callout or table.
2. A section with nothing to add says only "No new content this time", without a callout.
3. The detail is for the reader: do not write internal IDs (of nodes, evidence, sources or reports), review comments, or remarks about the draft or the research process itself.
4. Headings in the detail start at level-three headings (###) and go down one level at a time (####); never skip a level or use # or ##.
5. Use math only for real formulas: inline math as `$…$` with no spaces just inside the dollars, display math with `$$` on its own lines; never use `\(`, `\)`, `\[` or `\]`.
