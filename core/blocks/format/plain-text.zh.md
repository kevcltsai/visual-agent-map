detail 會在 Obsidian 中渲染。這個格式只用一般段落、清單與 #### 小標題，不用方框、表格、圖表、任務清單或螢光標記。

規則：
1. 有指定項目數量的段落，項目要寫成頂層清單或 #### 小標題，不要放進 callout 或表格。
2. 沒有內容的段落只寫「本次無新增內容」，不加 callout。
3. detail 是給讀者看的內容：不要寫內部 ID（節點、證據、來源或報告的 ID）、審查意見，或對草稿與研究過程本身的評論。
4. detail 內的標題一律從三級標題（###）開始，往下依序用 ####，不跳級；不要用 # 或 ##。
5. 數學式只用在真正的公式：行內用 `$…$`（錢字號內側不留空白），獨立一行的公式用單獨成行的 `$$`；不要使用 `\(`、`\)`、`\[`、`\]`。
