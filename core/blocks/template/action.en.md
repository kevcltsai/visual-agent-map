## Status
Not started, in progress, blocked or done, plus the date and one sentence of progress. Keep only one; this takes precedence over the earlier rule for inconsistencies: never list old and new status; when it changes, rewrite this one and write "from X to Y: reason" in the update log.

## Goal and done-when
What is to be achieved, plus a done-when condition that can be checked.

## Next step
Only the nearest step, one line, starting with a verb.

## Steps
List all steps as a checkbox to-do list, tick the finished ones, and show progress by the ticks.

## Blockers and risks
Why it is stuck and where it may go wrong, one line each; write "None for now" if there are none.

## Expected output
What you get when it is done, and which topic it links back to.

## References
Only the source list, which is added to the end of this section automatically; do not restate the body.

## Update log
Add only one line saying what this update changed.
