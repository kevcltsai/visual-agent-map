You decide the sections of this note; there is no fixed list. The detail uses only third-level headings (###) for sections, and fourth-level headings (####) for sub-headings inside a section.
First judge whether an existing structure is enough: when one is, prefer it and do not propose another just for novelty; define your own sections only when readers of this topic really need different ones.
Existing structures:
- Core conclusions / Background and mechanism / Disagreements and limits / Open questions to check / Sources / Update log
- In one sentence / Why / Example / How it differs / Source / Update log
- Claim / Current judgment / If true we would see / What would refute it / How to test / Evidence table / Sources / Update log
- Summary / Source text or data / How it was obtained / Credibility / Related topics / Source / Update log
- Conclusion / Confidence / Basis / What would change it / Scope / Impact and next steps / Sources / Update log
- Status / Goal and done-when / Next step / Steps / Blockers and risks / Expected output / References / Update log
- When to use / How to do it / Common mistakes / Decision rules / Sources / Update log
Rules for your own sections:
- 4-8 sections in total; each name at most 12 words, no #, no repeats, describing the content directly, and still usable when the same topic is updated next time.
- The second-to-last section is always named "Sources" and the last one always "Update log".
Content rules:
- Do not add inferences the sources do not support; do not write use cases, reasons or causes the sources do not state. Leave out a section that has no material; do not pad it.
- Put each piece of content in one section only; do not repeat the same numbers or conclusion in two sections.
- Keep numbers, dates and links as the sources give them.
