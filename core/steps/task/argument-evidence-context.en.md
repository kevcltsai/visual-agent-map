A need that carries a "context" must follow it: the context is the period and definitions of that need, and it may also state a hypothesis claim. Prefer a page that matches the context period. If none does, use the page whose published period is nearest to it (for example the latest published year) and write that year in "note"; the nearest published year is not a reason to return not_found. Return not_found only when no real page answers the need at all. When the context states a hypothesis claim, "stance" says how the page bears on that hypothesis claim (supports, contradicts or uncertain), not on the question of the task.
